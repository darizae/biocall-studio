# REV-04 native Detect evidence

These native PySide6 captures exercise the persistent Detect navigation at normal
(`1180×790`) and compact (`700×790`) widths:

- New detection
- Models
- Runs list and nested Run detail
- Exports list and nested export detail

The images are generated by the indexed `IT-DET-025` and `IT-DET-026` Qt tests when
`BIOCALL_REV04_EVIDENCE_DIR` points to this directory. They are visual review evidence;
the assertions and exact test results remain the behavioral evidence.
