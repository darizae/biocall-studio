## Scientific inspections (make paths concrete during implementing spec)

- **Spec 03:** locate source WAV/frame/channel conversion, protected windows or negative sampling where genuinely reusable, dataset and split serialization tests. Compare source-time units and our `target`/`noise` contract; use adapter or domain implementation only for verified overlap.
- **Spec 04.5:** inspect the separate toolbox's audio I/O API, write/test a reusable streaming WAV extraction utility upstream, then verify byte-equivalence and installed Worker import under [Spec 04.5](../specs/SPEC_04_5_UPSTREAM_AUDIO_EXTRACTION.md).
- **Spec 05 CNN:** inspect **separate sibling** `../bioacoustics-dl-toolbox` actual architecture/trainer/checkpoint/preprocessing API. For orchestration reference inspect `../alpaca-pipelines/src/alpaca_pipelines/training/executor.py`. Require complete saved configs/weights/class mapping and trusted **structural** reload; do not implement scoring.
- **Spec 05 RF:** inspect `../alpaca-pipelines/src/alpaca_pipelines/rf_training/`, `rf/audio_features/` and `rf/audio_preprocess.py` (actual local SHA). Fit/validate using true RF features; persist feature names/order, preprocessing/config, estimator `classes_`, threshold policy. RF `rf_inference/` is **future Prediction-only**, not Trainer work. Toolbox RF feature defaults are not assumed equivalent.
- **Scientific export and required indexed cases:** [Model export contract](../science/MODEL_EXPORT_CONTRACT.md). [Prediction plan](../PREDICTION.md) is deferred.
- **Spec 06/07:** document pinned scientific runtimes, CPU support and bundled worker imports; do not rely on source tree from installed app.

When actual paths/versions are confirmed, write a concise source-inspection record in the implementing PR; when upstream changed, include **both repositories' branches, real commit SHAs, library test results, Trainer reinstallation/import resolution and integration tests** per [upstream workflow](UPSTREAM_TOOLBOX_WORKFLOW.md). do not hardcode hypothetical references into core docs. HPC archive is optional *source evidence*, never a live test data dependency.

**Transfer note:** `tests/data/` payloads may be absent from the ZIP by design; look for registered Git LFS fixtures in the actual checkout or generate deterministic temporary WAVs. This has no bearing on the existence or path spelling of `../alpaca-pipelines` or `../bioacoustics-dl-toolbox`.
