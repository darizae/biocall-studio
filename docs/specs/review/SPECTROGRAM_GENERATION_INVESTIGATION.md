## 2. Historical pipeline: scientific quantities versus presentation

Reconstruct from `spectrogram_generation/R/spectrogram_helpers.R` and the Python/R generation scripts rather than assuming historical output images are scientifically ideal:

1. Decode 16-bit/other supported WAV to real samples; historical R used `tuneR::readWave`, per-file DC subtraction and stereo **waveform averaging**. That averaging can cancel out-of-phase content, and is **not** the newly approved multi-channel policy.
2. Full **non-centered**, non-padded 2,000-sample frames at 48,000 Hz; symmetric Hann `0.5−0.5cos(2πk/(N−1))`; hop 1,000 samples (50% overlap); unscaled 2,048-point real FFT with tail zero padding; power `|FFT|²`. Frame time is `(start+(N−1)/2)/fs`, frequency centers `k*fs/2048`. A longer analysis window improves ability to distinguish close frequencies, while it blurs rapid changes; zero-padding interpolates frequency samples but adds **no** resolution.
3. Crop selected frequency band (historical 0–3,000 or 0–4,200 Hz), divide by the **maximum power in the cropped image**, map `10 log10(power/peak)` to e.g. `[-50,0] dB` with a documented finite floor. Relative image intensity is not dB SPL and cannot prove absolute loudness differences across clips. Keep *linear* frequency for audible-call inspection. The new approved stereo mode averages per-channel **powers** before peak normalization, preserving opposite-phase energy; characterize its intentional difference from the R reference.
4. Historical publication plots use Magma/Turbo and sometimes explicit resampling (12× time, 7× frequency), then raster interpolation; axes/title embedded in canvases up to 3600×2250. Enlarging or smoothing **changes presentation only**. Review cache images contain **data pixels only**. Time/frequency ticks and detected boundaries belong to Qt, not PNG.
5. Some R scripts prepend/append 0.12 s of silence and expect an external manifest/Mac paths absent from the supplied archive. Do **not** silently add this silence to Review context. Build an independent numerical R reference fixture or manually verified array rather than claim full pixel parity with absent artifacts.

**Python option:** compare NumPy `rfft` with explicit framing to SciPy `ShortTimeFFT`; use pinned symmetric Hann, explicit no-centered/no-border semantics, true power (not silently PSD, magnitude, mel or dBFS), and validated frame-center/edge coordinates. `scipy.signal.spectrogram` is a legacy API; any use needs a specific justification. Pillow is a plausible controlled PNG encoder; Qt `QImage`/`QPainter` owns native display. Verify actual packaged dependency versions/availability, runtime import origins, macOS/Windows behavior and memory; do not assume the prototype canvas is a native rendering technique. References: https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.ShortTimeFFT.html and https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.spectrogram.html .

## 3. Proposed user settings contract for qualification

See [approved decisions and copy](SPECTROGRAM_DECISIONS.md). One **protected Default** and user-created named presets. The simple choices are:

| Setting | Default / allowed choices | Scientific meaning | Concise researcher tooltip |
|---|---|---|---|
| **Frequency range** | 4.2 kHz default; up to 3 / 4.2 / 8 kHz | Top displayed frequency; never exceed audio Nyquist | “Sets the highest pitch shown. A lower limit enlarges low sounds, but hides higher ones.” |
| **Sound detail** | **Balanced** (historical 2,000/48k ≈ 41.7 ms); **Fast changes** (≈21 ms), **Close pitches** (≈83 ms) | Window duration: time-vs-frequency resolution | “Short windows show when sounds change; long windows help separate similar pitches.” |
| **Time around call** | 2 s each side default; 1 / 2 / 3 s | Context requested on both sides, clamped to actual recording frames | “Shows more or less sound before and after the detected call.” |
| **Contrast** | 50 dB default; 40 / 50 / 65 dB | Dynamic-range floor relative to this image's brightest spectral value | “Shows quieter sounds. Higher contrast range may also reveal more background noise.” |
| **Colors** | Magma default; Viridis | Palette only; never changes audio or power | “Changes the colors without changing the sound or measurement.” |

**Advanced** (collapsed initially, three controls, not a second workflow):

| Setting | Proposed bounded input | Why it belongs behind Advanced |
|---|---|---|
| **Exact sound window** | **Use Sound detail choice** or curated 20/25/30/40/50/60/80/100 ms choices | Precise STFT window; custom mode overrides the simple Sound detail choice and must display its effective rounded samples. At 48 kHz, Balanced always retains exactly 2,000 samples (41.667 ms), not rounded 42 ms. |
| **Window overlap** | 50% default or 75% | Higher overlap adds more time slices, CPU/storage pressure and smoother changes; it does not increase underlying frequency resolution. |
| **Lowest frequency** | 0 Hz default; 100 / 300 Hz | Excludes low rumble visually but can hide biological low-frequency content. Require min < effective max. |

`n_fft` (next power of two >= window length, at least 2048 for historical Balanced/48k), symmetric Hann, channel-power aggregation, DC removal policy, linear frequency axis, frequency bin interpolation, per-image peak-reference rule, interpolation algorithm, image tiers, PNG compression and algorithm/version stamps remain **internal**; compare meaningful alternative implementations in the experiment before freezing the *native* numeric specification. No 50-choice advanced controls. Test min/max, sample rate rounding, short-clips and silent/zero-power audio without dividing by zero. Both default and Advanced settings are versioned together.

**High-DPI/tier policy:** Generate all produces only thumbnails; large inspection image is on demand. Use 320×120 thumbnail and 1200×450 detail **as pilot test points, not final native quality mandates**; fix tiers after actual Qt sizing/zoom/HiDPI tests. Never expose arbitrary output pixel sliders in ordinary settings. No embedded axes/call highlights in cached files. Separate **scientific changes** (window, overlap, channel policy, context, band limits, peak reference) from **presentation changes** (palette, contrast, pixel tier, interpolation). A palette change invalidates the image, not necessarily a reusable numerical intermediate; measure whether such an intermediate merits caching.

## 4. Experiment protocol and mandatory evidence

**All experimental rows** must carry: repository baseline and commit if verifiable, numerical algorithm/renderer/encoder version, Python/SciPy/NumPy/Pillow/Qt versions and origin, platform/architecture/CPU/RAM/device/volume, source hashes, `fs`/channels/dtype, duration, real or synthetic/fixture provenance, exact window/FFT/hop/f-range/contrast/palette/pixel tier/codec, cache state, worker count, repetitions, observed wall/CPU time, output bytes, peak RSS, quantiles and error flags. No false hardware-independent guarantee.

1. **Numerical validation.** Verify exact R-compatible mono window frames, symmetric taper, FFT/power array, cropped-peak dB calculation, pure tones, chirps, impulses and silent input; quantify tolerance and reasons for differences from `ShortTimeFFT`. Include phase-opposed stereo clips (power aggregation versus historical averaging), 8/16/24/32-bit PCM and multiple sample rates, odd frame counts, source ends, no-valid-window case and nonfinite/invalid settings. Confirm decibel floor and that colour interpolation cannot create false time/frequency coordinate claims.
2. **Representative inputs.** Start with both bundled 48 kHz mono WAVs (0.60/0.75 seconds); they are **insufficient** for natural context. Add consented genuine 3–10 s context clips across sparse/dense/noisy/quiescent calls; at least one 8/16/24/48/96 kHz source where supported; mono/stereo/inverted channels; candidates close to start/end and several neighboring detections in one recording. Never use private/source paths in published benchmark rows.
3. **Parameter matrix.** Baseline and 21/42/83 ms, 50/75% overlap, 0–3/4.2/8 kHz, 0/100/300 Hz floor, 40/50/65 dB, two palettes, and both context extents; isolate one change at a time before testing worst combinations. Compare no image interpolation versus specified interpolation; measure STFT time separately from RGB mapping/encoding and check resulting images visually with original WAVs.
4. **Tier, codec and display.** Render 320×120, 1200×450, plus one oversized 3600-wide reference, with axes omitted. Measure serialized bytes, encode/decode, first cold disk read, warmed cache disk read, native Qt resize/paint at 100%/150%/200% scale and Gallery/List/One by one. Distinguish numerical spectrogram generation, first image generation, cached display and data-only image rendering; test native paint rectangles/high-DPI rounding.
5. **Scale and supervision.** Measure cold/warm 1/10/50/100/1000 distinct candidates and 10k/50k **analytical** estimates; optionally run actual 10k/50k only where resources and source access permit. Record queue overhead, CPU/IO saturation, cache hit proportion, true output bytes, filesystem metadata, staging peak, process shutdown/cancel/retry and 50k scroll/label latency under load. Avoid 50k static image widgets or megabytes of per-candidate persisted state. Model shared source read and digest caching only after correctness.
6. **Calibration.** For each cohort compare predictions with actual bytes/time; report calibrated quantile intervals (e.g. P10/P50/P90) and stratification for duration/sample rate/complexity/tier. State cohort counts and extrapolation error; hold out recordings. If calibration is weak, classify estimate as unavailable/low confidence and give an honest broad range or unknown, not one fabricated second/MB number.

### Existing bounded pilot (measured 2026-11-03; NOT native production evidence)

Sandbox: Linux x86_64 / Python 3.13.5 / NumPy 2.3.5 / SciPy 1.17.0 / Pillow 12.3.0; pilot had **no Qt, macOS/Windows or real representative context**. Source fixtures are mono 48 kHz 16-bit 0.60 s and 0.75 s. One constructed 5 s clip contains both fragments and mostly silence.

| Measured case | 320×120 PNG median generation | 1200×450 PNG median generation | bytes (thumb / detail) | Interpretation |
|---|---:|---:|---:|---|
| Real 0.75 s WAV | 11.2 ms (5 runs) | 142 ms (3 runs) | 35,863 / 263,889 | Small dense content, not realistic 5 s context |
| Constructed 5 s (mostly silence) | 7.08 ms (5 runs) | 45.9 ms (3 runs) | 19,279 / 155,183 | Artificially high compression; not a natural lower bound |

**Measured:** constructed 5 s STFT 2.97 ms (10 runs, no audio disk reading); 75% overlap STFT 6.77 ms; cached detail PNG **in-memory Pillow decode** 9.15 ms (20 runs; excludes disk, Qt). A 100-image thumbnail batch of the *same fabricated clip* took 0.7433 s and is not a representative independent-file workload.

**Analytical scenario, not forecast:** blindly multiplying the observed per-image file sizes by 50,000 gives 0.90–1.67 GiB for thumbnails and 7.23–12.29 GiB for details across these two examples, **excluding** metadata, retries, staging, and input variation. Do **not** promote these extremes to estimator calibrated bounds. Missing numerical R fixture means cross-language parity is unproven. Full reproduction script, source SHA-256 and raw observations were delivered separately in `biocall-spectrogram-investigation-phase1.zip` / `pilot_benchmark.py`; archive is external to this patch, not part of the source repo.

## 6. Session settings, preset identity and cache lifecycle

A built-in read-only **Default**, available from Review → Spectrograms → Settings and session-start. Create user presets from current, name uniquely, edit in an unsaved draft, compare/test, **Save** only after confirmation. Confirmation distinguishes saved user preset (future selections) from the effective settings already frozen into sessions. Count sessions referencing that preset and list Open/Closed/Finalized counts without exposing IDs or implying automatic regeneration. **Do not propagate edits to them.** If the currently Open session is one of them, offer a distinct **Save & use in this session** action with new cache/time estimates and explicit invalidation; otherwise **Save preset** keeps all sessions unchanged. Renames follow the same stable-ID/revision process; deletion needs confirmation, affects menu availability and saved examples only, never existing session snapshots/labels. Default cannot be edited/deleted; to customize it use **New preset**.

Each Review session stores a versioned immutable *effective settings snapshot* including scientific/display parameters, backend pipeline revision, preset ID/name/revision **at selection time**. Existing snapshots survive later preset edits, rename, deletion and session close/restart. Only Open can change effective settings; Closed must Resume, Finalized can inspect/export only, and successor inherits a *copy* of its finalized parent's settings snapshot as initial state (never rewrites parent). Settings changes do not mutate candidate eligibility, source frames, annotations, undo history, Result or export. Failed compare-and-swap / disk preflight leaves original settings/cache active. Freeze snapshot provenance in finalization metadata **without including cached PNG bytes**; do not change the corpus payload truth table or require images for exports.

Session **Change preset** shows old/new names, actual differences, affected thumbnail count, incremental time/bytes bounds, available cache space and plainly states **“Existing spectrogram images for this session will need to be generated again. Labels and recordings won't change.”** Confirm then atomically advance session settings revision/epoch and switch active cache references; never physically erase globally shared files merely because a session changed settings. Publish generated files only under verified content keys and matching revision/epoch/source; stale in-flight jobs may finish privately but may **never** appear under the new snapshot. Cancel preserves valid compatible outputs; retry only missing/failed. Visible thumbnails and current detail regenerate first, neighboring prefetch bounded, **Generate all** only remaining thumbnails subject to REV-05. Quota, LRU, clear-one/selected/all, restart, exit and busy Review Workers must obey existing RV-02/RV-04/RV-07 lifecycles. A saved preset edit is never a mass-update or surprise background job across sessions.

Content key = digest(versioned algorithm+effective settings+validated source identity+candidate original frames+exact context frames+channel policy+pixel tier+colour/raster version); session epoch controls *which* key is publishable, not scientific content identity. Keep staging private, validate containment/symlinks and checksum, atomically rename and commit manifest, do not let a canceled/late renderer resurrect a stale session artifact. Valid globally reused images may remain until unreferenced and evicted; intentional **Clear spectrograms** still frees disk space while preserving labels. Test repeated edits, loss of source, concurrent sessions and crash just before manifest commit.

## 7. Axes and exact UI geometry (native obligation)

Generated file is **data-only**. The coordinate contract must be unambiguous: recording digest, original and clamped context frame `[start,end)`, candidate `[start,end)`, source fs/channel policy, frame alignment/centering, window and FFT/hop samples, exact first/last centers, populated time and frequency bin centers/edges, min/max displayed frequency, interpolation/cropping policy, image pixel width/height, time origin convention, linear axis orientation, image palette/contrast and algorithm+renderer version. For clamped boundaries and short clips, **do not fabricate silent margins** unless explicitly versioned and indicated. If there are too few samples for one full window, choose a documented edge policy and qualify it separately; no fake data.

Define image bin-to-pixel transform over an explicit **true displayed context extent** in source frames; if the renderer extends edge bins, record half-bin boundaries so Qt ticks and overlays match raster *edges*, not merely first/last frame centers. Detection highlight X edges derive from the same transform as the image: exactly `(candidate_frame−context_start_frame)/(context_end_frame−context_start_frame)` only when the image time extent is that whole frame range. Frequency ticks map actual selected `f_min..min(f_max,fs/2)`; no hardcoded 8k or six-second axis. Source rate below selected max: show actual extent and an intelligible limited-range note, not a mislabeled 8 kHz axis. Native `QPainter` draws pixels/axes/highlight in shared `QRectF` device-independent coordinates with HiDPI scale and resize recalculation. Gallery needs a compact aligned highlight, List may omit image/axes, One by one shows tick labels. Tests: zero/short clips, left/right clamping, odd-rate/stereo, every tier, 100/150/200% DPI, changing presets on same candidate, image corruption/mismatched metadata.
