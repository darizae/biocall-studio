## Deliverable and responsibilities

- This historical stage introduced the canonical Studio entry. REV-01 supersedes its temporary dual-package constraint: `python -m biocall_studio` and `biocall-studio` are now the only public launches, and all supervised Workers use the private canonical CLI.
- Start at a native **BioCall Studio** launchpad with three keyboard-operable, accessible cards: **Train** (opens the actual Train experience), **Detect** (a truthful native landing placeholder), and **Review** (Coming later). Use the checked-in branding, `alp-ui` components, typography, spacing and colors. No simulation banners, HTML prototype controls, arbitrary scientific values, or implementation commentary in product text.
- A persistent, discoverable **Back to Studio** action must work from Train at normal and compact sizes. Use the smallest optional hook into Train's existing `MainWindow` (independently usable without the shell); do not alter Train routes/pages or replace its sidebar and Run header. Detect and Review return to Studio. Switching back and forth preserves **the same Train controller, route, open training draft, active scan and real Worker**. Do not create a new Train controller on each entry or cancel work on navigation.
- One application owns Qt theme installation, window lifetimes and app-exit coordination. REV-01 supersedes this stage's temporary settings-location and command constraints with versioned suite-owned workflow roots and the canonical CLI. Preserve diagnostic setup, Worker supervision and clean startup/failure behavior. A window switch is **not** an application close.
- Closing the **application** from either workspace applies Train's existing safe active-Run/scan shutdown semantics once: declining an active-Run exit keeps the exact Run alive; confirming it waits for supervised stop before app quit. If a workspace is hidden when quit is requested, the confirmation must be visible and keyboard-operable. Idle exit releases resources without an unnecessary prompt. Avoid `quitOnLastWindowClosed` accidental exits, orphan QProcess/leases, duplicate diagnostic hooks or contradictory close dialogs.
- Detect has **no selectable Model, recording scanner, saved draft, fake Results or runnable button** in ST-02. Its landing surface is an honest, simple entry state and a way back. Review remains a placeholder. Other screens become native in their owning later stages.
