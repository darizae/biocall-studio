# BioCall Studio 0.1.0a1 — proposed alpha notes

**Provisional candidate, not a published release.** There is no Studio tag,
downloadable installer, signature, notarization or final source qualification.

BioCall Studio unites **Train → Detect → Review** in one native PySide6
desktop application. Researchers can assemble labeled training data, build CNN
or Random Forest models, scan recordings, inspect detections in a
source-linked spectrogram gallery/list/one-by-one view, listen to audio,
label and resume review sessions, and export reviewed WAV clips and
Raven-compatible annotation tables. Original source recordings remain read-only.
The README uses genuine existing macOS Cocoa Train/Detect/Review screenshots,
not imagery from installed distributable binaries.

This candidate consumes the **published** `alp-ui 0.1.0a1` and
`bioacoustics-dl-toolbox 0.3.0` wheels, including toolbox-owned
**display-only** spectrogram DSP. Existing CNN feature representations are not
replaced by the Review display raster. Python 3.11–3.13 is supported for source
development. Wheel SHA-256 values and exact upstream tag-target commits are in
[the candidate manifest](v0.1.0a1-manifest.md); install using the verified
wheelhouse in [the development guide](../DEVELOPMENT.md).

**Not yet available/qualified:** public app license and GPL/Qt redistribution
clearance, final wheel dependency lock, freezer/installer code, native macOS
and Windows installation/signing/clean-uninstall evidence, full local Studio
base-suite, and owner promotion approval. Stage 04 must merge packaging source
before the final source SHA can be frozen; stage 05 owns full qualification,
tagging and possible GitHub Release. No PyPI or public app distribution is implied.
