## Archive and worker contracts

Build Studio sdist/wheel as **source artifacts only**. The wheel must include
`TRAINING_CONFIGURATION_FIELDS.json`, the suite PNG/icon ICO/ICNS and
[`THIRD_PARTY_NOTICES.md`](../legal/THIRD_PARTY_NOTICES.md). The public entry
is `biocall-studio = biocall_studio.cli:main`, with `python -m
biocall_studio` also supported. Private `--worker` modes are
`train-dataset-build`, `train-cnn-training`, `train-rf-training`,
`detect-cnn`, `detect-rf-refinement`. The freezer must honor the same
dispatch and resources; this stage does not claim frozen workers are usable.

Scoped CI evidence and the provisional merged source SHA belong in the PR
handoff, not in a self-referential immutable manifest. **Blocked:** Studio
application license/Qt/GPL compatibility review; platform installation,
signing, notarization, final SHA, native artifacts, local full suite and tag.
