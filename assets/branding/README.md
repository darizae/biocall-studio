# BioCall Studio — shared suite mark

This is the **suite-level** asset set, not the icon of any single workflow app.

- `transparent/icon.png` — original mascot composition centered on a square transparent canvas.
- `transparent/lockup-light.png` / `lockup-inverse.png` — wordmark for light and dark surfaces.
- `on-background/readme-header.png` — README header for the shared toolkit.
- `icons/` — PNG sizes for UI and Windows `.ico` / prototype macOS `.icns` for an eventual suite shell or launcher.

Accent: shared emerald `#059669`. The top-right green tile is not modified from `alp-ui`.
