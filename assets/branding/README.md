# BioCall Studio Train brand assets

These files were copied from `BioCall-Studio/apps/train/assets/` at brand-kit version
`0.2.0-prototype`. The application does not depend on that checkout.

- `on-background/readme-header.png` is the repository README banner.
- `transparent/` contains the icon master and light/dark transparent lockups.
- `icons/icon-*.png` contains fixed-size exports for native UI and future packaging.
- `icons/icon.ico` is the Windows installer/shortcut source.
- `icons/icon.icns` is the macOS bundle source and still requires native Finder/Dock validation.
- `src/biocall_studio_train/resources/branding/icon-256.png` is the packaged Qt runtime copy.

The visual reuses the existing `alp-ui` alpaca-like raster mascot and adds the Train blue tile with
ascending bars. The source brand kit does not establish redistribution rights or trademark
clearance. Confirm authorship, licensing, attribution, and name availability before public
distribution or logo registration.
